# aliOS Console Backlog

Deferred console improvements, captured 2026-05-31 from first-use feedback after deploy. Revisit as "Stream A: console rework."

## Send / targeting
- **Send to all (broadcast):** fire a free-type message OR a library line to all players at once, not just the one selected in the sidebar.
- **Label the two send dropdowns:** the panel has an unlabeled "sender (who it is from)" dropdown and an unlabeled "target app (where it lands)" dropdown. Because "Allie" appears in both, it is unclear how to send to the Allie app. Add clear labels (and probably visually separate the two concepts).

## Library
- **Rework "+ New line":** replace the crude browser prompt with a real form: body text, optional label, optional image attach, and a phase gate (mark a line as available only from Phase N onward).
- **Edit existing library lines:** currently you can only delete and recreate.
- **Fire a library line to all:** ties to send-to-all above.

## General
- **Discoverability / layout polish:** the send panel, library, and editor tabs could be clearer about what each control does.

---
These are UX and console-side only. None block play; the core send/receive/phase/cutscene paths all work.
